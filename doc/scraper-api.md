# Routes : 

- `/add_artist` (POST)
  - `q` (string): querry string. ex : "Em Beihold"

- `/add_album` (POST)
  - `q` (string): querry string. ex : "Tales of a failed shapeshifter - Em Beihold"
Note : artist name is better to be provided for accurate search results but not mandatory

- `/add_track` (POST)
  - `q` (string): querry string. ex : "Scared of the dark - Em Beihold"
Note : artist name is better to be provided for accurate search results but not mandatory
